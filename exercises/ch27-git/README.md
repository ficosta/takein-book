# Capítulo 27 — Git e GitHub

Este capítulo não tem pasta de início: você vai versionar o seu
próprio pacote de news (`ch25-news/solution/news`, ou o seu), o
pacote dos gráficos `takein.news.*`, que estendem a `NewsGraphic`.

1. Copie a pasta `news` para fora de `exercises/`, por exemplo
   para `Documentos/news-package`.
2. Siga as seções 27.4 a 27.7 do livro, no terminal do VS Code,
   dentro dessa pasta. A cor que você troca nos exemplos é o
   `--accent` da pele news, no `tokens.css` do pacote.
3. Use o `gitignore-template.txt` desta pasta como `.gitignore`.
4. Na seção 27.8, crie um repositório **privado** no GitHub,
   com o nome `news-package`.
